📚 Sobre o projeto

Este site reúne as atividades desenvolvidas na disciplina de Programação Web, utilizando tecnologias como HTML5, CSS3 e JavaScript.

O objetivo é organizar os trabalhos realizados durante a disciplina e acompanhar a evolução dos conhecimentos adquiridos ao longo das atividades.
