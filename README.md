Neste repositório são armazenados os exercícios, atividades e projetos desenvolvidos durante a disciplina, utilizando tecnologias relacionadas ao desenvolvimento Web.

O objetivo é organizar os projetos e acompanhar a evolução dos conhecimentos adquiridos ao longo da disciplina.

## 🚀 Projetos e Atividades

- **Atividade 1:** Estruturação básica de páginas HTML5 (cabeçalhos, parágrafos, listas).
- **Atividade 2:** Página de produto com tabelas, especificações e imagens.
- **Atividade 3:** Estilização com CSS3, box model, cores e tipografia.
- **Landing Page:** Página temática Ayrton Senna com modo escuro/claro, layout responsivo e interatividade.
- **Atividade 4:** Mini-sistema de cadastro de produtos utilizando JavaScript, formulários, manipulação do DOM e persistência com `localStorage`.
- **Avaliação Prática (Catálogo com API & Favoritos):** Aplicação Web completa integrada à API pública DummyJSON utilizando Fetch API (`async/await`), pesquisa por texto, filtros por categoria, ordenação por preço e avaliação, modal de detalhes do produto e gerenciamento de favoritos com persistência via `localStorage`.
