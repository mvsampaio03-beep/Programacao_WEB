# Programação Web

Repositório destinado às atividades e projetos desenvolvidos na disciplina de **Programação Web**.

## 📚 Sobre o projeto

Neste repositório serão armazenados os exercícios, atividades e projetos desenvolvidos durante a disciplina, utilizando tecnologias relacionadas ao desenvolvimento Web.

O objetivo é organizar e acompanhar a evolução dos projetos realizados ao longo da matéria.

## 📝 Atividades

### Atividade 1

Desenvolvimento de uma página utilizando a estrutura básica do **HTML5**, incluindo:

* Estrutura `DOCTYPE`, `html`, `head` e `body`;
* Meta charset UTF-8;
* Título da página;
* Títulos e subtítulos;
* Parágrafos;
* Uso das tags `strong` e `em`.

### Atividade 2

Desenvolvimento de uma página de produto utilizando diferentes elementos do HTML5:

* Listas ordenadas e não ordenadas;
* Imagens;
* Links externos e internos;
* Tabela de especificações;
* `caption`, `thead`, `tbody` e `tfoot`.

## 💻 Tecnologias utilizadas

* HTML5
* Git 
* GitHub
* Visual Studio Code

## 🎯 Objetivo

Praticar os principais conceitos de desenvolvimento Web e aprender a utilizar ferramentas de versionamento para organizar os projetos desenvolvidos durante a disciplina.
